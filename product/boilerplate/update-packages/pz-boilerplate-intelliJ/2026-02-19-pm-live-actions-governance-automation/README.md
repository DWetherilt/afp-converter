# PM Live + Action Governance Automation

## Purpose
Promote the PM framework upgrades that make live console supervision persistent and enforce SQL-backed action/governance automation by default.

## Included capability
- Persistent `pmconsole live` daemon with PID/log management and default workflow integration.
- Native `pmconsole actions` command + live-command support.
- SQL action ledger enhancements (aging/SLA metadata).
- Automated action->decision suggestions.
- Strict ingest gate for prompt-derived action items.
- Realm policy sync and diff reports.
- Cross-realm SQL action token search.
- Reasoning report adds decision-link coverage metric.
