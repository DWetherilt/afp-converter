# Queue Normalization + Knowledge Link Gate

## Purpose
Promote a high-leverage PM cycle that:
- normalizes open action queue items into concrete owner/decision-linked tasks,
- mirrors and gates knowledge-link integrity across realms,
- hardens strict verification path behavior,
- and improves console command UX for action/knowledge operations.

## Included outcomes
- strict `realmKnowledgeLinkGateStrict` in quality path,
- `realm knowledge status` console report,
- action filters (`owner`, `open-only`) and suggestion-apply command,
- updated policy/data-dictionary/workflow integration.
