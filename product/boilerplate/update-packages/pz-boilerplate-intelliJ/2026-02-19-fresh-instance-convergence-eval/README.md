# Fresh-Instance Convergence Evaluation

## Purpose
Provide a deterministic handoff pack for a fresh AI instance to:
- apply the latest approved boilerplate roll-up,
- run standard validation gates,
- report convergence/deltas against the current `afp-converter` PM framework.

## Primary dependency
- `2026-02-18-pm-realm-console-sql-rules-rollup`

## Included files
- `package-manifest.json`
- `apply-checklist.md`
- `fresh-session-prompt.md`
- `comparison-checklist.md`

## Expected result
A fresh session should reach substantially the same PM framework behavior (workflow, gates, state/report paths, and console commands) with differences explicitly documented.
